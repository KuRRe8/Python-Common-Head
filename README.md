## What

A utility package for daily Python usage.

## Install

> [!TIP]
> It's not compulsary to install the package. You can use it directly. Just copy the subfolder to your project.

```bash
pip install .
```

## Usage

```python
from python_common_head import *
```

The file [try_head_file.py](try_head_file.py) can be used to detect what has been imported.
